# Python CLI To-Do List

A simple and practical command-line To-Do List application built with Python.  
This project allows users to add, view, delete, and clear tasks, with full support for saving tasks in a file.

## Features
- Add new tasks
- View all tasks
- Delete tasks by number
- Clear all tasks
- Tasks are saved in tasks.txt and loaded automatically
- Clean and simple CLI interface

## Installation & Usage

1. Clone the repository:
   git clone https://github.com/miladzendehboudi/todo-cli

2. Navigate to the project folder:
   cd todo-cli

3. Run the script:
   python main.py
